# ใช้ส่วนตัว vs ให้บริการผู้อื่น

ตัวช่วยเขียน caption (`tools/caption/`) เรียก `claude` ในเครื่อง มี 2 โหมด ดูได้ด้วย
`node --import tsx tools/caption/cli.ts --auth-check`

## ส่วนตัว
ใช้กับร้านของคุณเอง ในเครื่องของคุณ ด้วยล็อกอินของคุณเอง (เปิด `claude` แล้วพิมพ์ `/login`)
ไม่ต้องตั้ง `ANTHROPIC_API_KEY` → เครื่องมืออยู่ในโหมดล็อกอิน

## ให้บริการ
ถ้าจะทำเป็นบริการให้ร้านอื่นใช้ (เช่น SaaS) **ห้ามใช้ล็อกอินส่วนตัวของคุณ** ต้องใช้ **API key**
ของบริการนั้นเอง ตั้งผ่านตัวแปรสภาพแวดล้อม `ANTHROPIC_API_KEY` → เครื่องมืออยู่ในโหมด api-key

## API key
- ใส่ใน `.env` (ไม่เข้า git; `.env.example` มีบรรทัด `ANTHROPIC_API_KEY=` ว่างไว้เป็นแบบฟอร์ม)
- `--auth-check` ตรวจแค่รูปแบบ (ขึ้นต้น `sk-ant-` ยาว ≥ 20 ตัว) ไม่ยิงเน็ต และไม่พิมพ์ key ออกมา
- ห้ามวาง key จริงในแชทหรือไฟล์ที่ commit
