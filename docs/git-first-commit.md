## ขั้นตอนที่ต้องทำเองตอนมีบัญชี GitHub

ตอนนี้ยังไม่ push ใด ๆ เมื่อมีบัญชีแล้ว:

1. เข้า github.com แล้วสร้าง repository ใหม่ **ที่ว่างเปล่า** (ไม่ติ๊กสร้าง README, .gitignore หรือ license เพราะในเครื่องมีอยู่แล้ว)
2. คัดลอก URL ของ repo ที่ได้ แล้วรันในโฟลเดอร์โปรเจกต์:

   ```
   git remote add origin <URL ของ repo>
   git push -u origin main
   ```

3. ครั้งแรก GitHub จะขอยืนยันตัวตน (Personal Access Token หรือ SSH key) ตามที่ตั้งไว้ในบัญชี
4. รีเฟรชหน้า repo บนเว็บ ต้องเห็นไฟล์ แต่ไม่เห็น `.env` กับ `node_modules`

หมายเหตุ: `.claude/settings.json` ตั้งให้ถามก่อนทุกครั้งที่ `git push`
