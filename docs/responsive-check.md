# ผลตรวจการเลื่อนแนวนอน (responsive check)

วิธีตรวจ: เปิดหน้าเว็บด้วย Chromium (playwright-core) ที่ viewport สูง 800 px
เทียบ `scrollWidth` ของหน้ากับ `clientWidth` และหา element ที่ขอบขวาเกินความกว้างจอ

## ก่อนแก้
| ความกว้าง | ผล | หมายเหตุ |
|---|---|---|
| 375 px | ไม่ผ่าน | scrollWidth 720 > 375 เลื่อนแนวนอนได้ |
| 768 px | ผ่าน | 768 = 768 |
| 1280 px | ผ่าน | 1280 = 1280 |

ต้นเหตุ: แถบโปรโมชัน (`.promo-bar` ใน `web/index.html`) ตั้ง `min-width: 720px` แบบ inline
จึงกว้างกว่าจอมือถือ

## การแก้
ลบ `min-width: 720px` ออกจาก style ของแถบโปรโมชัน แถบและข้อความของทีมการตลาดยังอยู่ครบ
แถบกว้างเต็มจอและข้อความขึ้นบรรทัดใหม่เอง

## หลังแก้ (ตรวจทั้ง dev server และ build จริงผ่าน vite preview)
| ความกว้าง | ผล |
|---|---|
| 375 px | ผ่าน (375 = 375) |
| 768 px | ผ่าน (768 = 768) |
| 1280 px | ผ่าน (1280 = 1280) |

## ยังไม่ได้ตรวจ
- ตรวจเฉพาะ Chromium ไม่ได้ลอง Safari/Firefox หรือมือถือจริง
- ไม่ได้ดูหน้าตาด้วยสายตา ตรวจเฉพาะตัวเลขความกว้าง
- ตรวจเฉพาะหน้าแรก (ยังไม่มีหน้าย่อย)
