# Brief: ใบเสนอราคา Coffee Break ให้ออฟฟิศ
> ข้อมูลสมมติเพื่อการเรียน · หนึ่งหน้า

## ปัญหา
ออฟฟิศแถวร้านสั่งกาแฟกับเบเกอรี่ไปประชุมบ่อย ๆ เจ้าของร้านต้องนั่งคิดราคาและพิมพ์ใบเสนอราคาเองทุกครั้ง (บางครั้งคิดผิด)

## ผลที่ต้องได้
คำสั่ง `npm run quote -- orders/ออฟฟิศสมมติ.json` อ่านคำขอ (JSON) แล้วได้ไฟล์ใบเสนอราคา PDF ภาษาไทยใน `out/` เลขที่ `QT-YYYYMMDD-NNN` (วันที่ของคำขอ · NNN เริ่ม 001 ของวันนั้น นับจากไฟล์ที่มีอยู่แล้วใน `out/`)
และพิมพ์หนึ่งบรรทัดสุดท้ายว่า `ยอดสุทธิ <ตัวเลขมีจุลภาค> บาท → <ไฟล์ PDF>`

## ของที่มีให้แล้ว (อย่าเขียนซ้ำ)
- `tools/quote/catalog.ts` อ่านราคาจาก `data/menu.csv` และข้อมูลร้านจากตาราง `settings` (ตัวแปร `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`)
- `tools/quote/pdf.ts` วาด PDF จากผลที่คำนวณแล้ว · `tools/quote/types.ts` ชนิดข้อมูล
- `tools/quote/quote.test.ts` คือ test ที่ใช้ตัดสินว่าเสร็จ (ยังรันไม่ผ่านเพราะยังไม่มี `pricing.ts`)

## กฎของร้าน (สิ่งที่ AI เดาเองไม่ได้)
1. ราคาต่อหน่วยมาจาก `data/menu.csv` ตามชื่อที่ตรงเป๊ะ · **ห้ามพิมพ์ราคาซ้ำในโค้ด**
2. ราคาแก้วละไซซ์ M ไม่คิดตัวเลือกเสริมในใบเสนอราคา (ใบเสนอราคาคิดตามรายการในเมนูเท่านั้น)
3. ส่วนลดคิดจาก **จำนวนแก้วเครื่องดื่ม** ทั้งใบ: 30–49 แก้วลด 10% · 50 แก้วขึ้นไปลด 15% · ลดเฉพาะยอดเครื่องดื่ม (เบเกอรี่ไม่ลด) · เศษของส่วนลดปัดขึ้นเป็นบาทเต็ม
4. ค่าส่ง: ถ้าให้ร้านส่ง และยอดหลังหักส่วนลดต่ำกว่า 1,500 บาท คิด 100 บาท ถ้า 1,500 บาทขึ้นไปส่งฟรี · รับที่ร้านไม่คิดค่าส่ง
5. **ยังไม่คิด VAT** ห้ามเพิ่มบรรทัดหรือการคำนวณภาษีเอง
6. ข้อความที่เจ้าของร้านเห็นเป็นภาษาไทย ไม่มี stack trace: ชื่อรายการที่ไม่มีในเมนูให้หยุดและบอกว่าชื่ออะไร

## เสร็จเมื่อ
- `npm test` ผ่านทั้งหมด
- `npm run quote -- orders/ออฟฟิศสมมติ.json` ได้ PDF และบรรทัดสุดท้ายบอกยอดสุทธิ 2,880 บาท
- รายงานว่าอะไรที่ยังไม่ได้ตรวจ (เช่น หน้าตา PDF จริงบนจอ)
