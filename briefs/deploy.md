# Brief: เอาเว็บร้านขึ้นออนไลน์ (Cloudflare Workers + static assets)
> ข้อมูลสมมติเพื่อการเรียน · หนึ่งหน้า · ยังไม่ต้องสมัครบัญชี: บทนี้เตรียมทุกอย่างให้พร้อมและตรวจด้วย dry-run

## ปัญหา
เว็บร้านดูได้แค่ในเครื่องเรา ลูกค้าเข้าไม่ได้ อยากได้ URL จริงที่ส่งต่อให้เพื่อนและลงใน Instagram ได้

## ผลที่ต้องได้
- ไฟล์ `web/wrangler.jsonc`: ชื่อ Worker ชื่อ `story-cafe`, `compatibility_date` เป็นวันที่ใกล้ปัจจุบัน, ใช้ static assets จากโฟลเดอร์ `./dist`, ตั้ง `not_found_handling` เป็น `single-page-application` (หน้าย่อยจะมาในบทหลัง ๆ)
- ใน `web/package.json`: `wrangler` เป็น devDependency และมีสคริปต์ `deploy` (build แล้ว `wrangler deploy`)
- `cd web && npx wrangler deploy --dry-run` ต้องผ่าน (dry-run ไม่ต้องล็อกอิน ไม่ส่งอะไรขึ้นอินเทอร์เน็ต)
- ผลลัพธ์ที่สร้างใหม่ได้ (`web/dist/`, `.wrangler/`) ไม่เข้า git: โค้ดเข้า git แล้ว build ใหม่ทุกครั้ง

## กฎ (สิ่งที่ AI เดาเองไม่ได้)
- **ไม่มีความลับในไฟล์ที่เข้า git**: ห้ามใส่ API token ของ Cloudflare ในไฟล์ใด ๆ ครั้งแรกที่ deploy จริง ให้ผมล็อกอินผ่านเบราว์เซอร์ด้วย `npx wrangler login` เอง (ไม่ต้องคัดลอก token มาที่แชต)
- ตัวแปรที่ขึ้นต้น `VITE_` จะถูกฝังในไฟล์ที่ลูกค้าโหลดได้ทุกคน ห้ามใช้กับค่าลับ
- ห้ามรัน `wrangler deploy` จริงในบทนี้ (ยังไม่มีบัญชี) ใช้ `--dry-run` เท่านั้น
- เปิดดูเว็บที่ความกว้าง 375 / 768 / 1280 px แล้วต้องไม่เลื่อนแนวนอน

## เสร็จเมื่อ
- dry-run ผ่าน และรายงานตัวเลข Total Upload ที่ได้
- รายงานขั้นตอนที่ผมต้องทำเองตอนมีบัญชี Cloudflare (login, deploy ครั้งแรก, ชื่อ `*.workers.dev` ที่ได้) และอะไรที่ยังไม่ได้ตรวจ
