# Brief: หน้าแรกเว็บ Story Cafe
> ข้อมูลสมมติเพื่อการเรียน · หนึ่งหน้า (ยังไม่ต้องมีหน้าสั่งของ ระบบสั่งจะมาในบทหลัง)

## ปัญหา
ลูกค้าได้ยินชื่อร้านจากเพื่อน ค้นชื่อร้านแล้วไม่เจออะไร ไม่มีเว็บ ไม่รู้ว่าร้านเปิดกี่โมง มีเมนูอะไร

## แนวทางภาพ
คาเฟ่ specialty มินิมอล โทน **ครีม + เขียวมะกอก + สีไม้** ภาพที่ถ่ายลง Instagram ได้ · ใช้ skill `frontend-design` · ฟอนต์ไทยแบบไม่มีหัว: Kanit จาก `/fonts/Kanit-Regular.ttf` และ `/fonts/Kanit-SemiBold.ttf` (อยู่ใน `web/public/fonts/` แล้ว ห้ามโหลดฟอนต์จากอินเทอร์เน็ต)

## โครง (หน้าเดียว เลื่อนลง) ใน `web/`
1. **Hero:** ชื่อร้าน + คำโปรย + ปุ่ม LINE และปุ่มโทร
2. **เมนู:** แยกตามหมวด **อ่านจาก `src/menu.ts`** (ข้อมูลมาจาก `data/menu.csv`) ห้ามพิมพ์ชื่อหรือราคาเมนูซ้ำในโค้ด
3. **ของขายออนไลน์:** เมล็ดกาแฟกับ drip bag (อ่านจาก `shop.products`)
4. **Workshop latte art:** วัน เวลา ที่นั่ง ราคา (อ่านจาก `shop.workshop`)
5. **ที่ตั้งและเวลาเปิด:** ที่อยู่ เวลาเปิด ปุ่มเปิดแผนที่ (ลิงก์ค้นหา Google Maps ไม่ฝังแผนที่)
6. **ท้ายหน้า:** ชื่อร้าน Instagram LINE และข้อความ "ข้อมูลสมมติเพื่อการเรียน"

## กฎ (สิ่งที่ AI เดาเองไม่ได้)
- ไม่มีรูปถ่ายคนจริง ไม่มีโลโก้ของแบรนด์จริง: ใช้ลายเส้น/สีไล่/รูปร่างด้วย CSS หรือ SVG
- ปุ่มโทรใช้ค่า `shop.phone` ที่เป็นเบอร์สมมติ `0X-XXX-XXXX`: ถ้าไม่ใช่ตัวเลขล้วน **ห้ามทำเป็นลิงก์ `tel:`** (ไม่ให้โทรออกหาเบอร์จริงใคร)
- เลื่อนแนวนอนไม่ได้ที่ความกว้าง 375 / 768 / 1280 px
- `<html lang="th">` และ `<title>` ภาษาไทยต้องคงอยู่
- ไม่โหลดอะไรจากอินเทอร์เน็ตตอนเปิดหน้า (ไม่มี CDN ฟอนต์ ไม่มีรูปจากเว็บอื่น)
- แก้เฉพาะ `src/App.tsx` และไฟล์สไตล์ใน `web/src/` (อย่าแก้ `menu.ts`, `main.tsx`, config)

## เสร็จเมื่อ
- `cd web && npm run build` ผ่าน ได้ `web/dist/index.html`
- รายงานว่าตรวจอะไรไปแล้ว **และอะไรที่ยังไม่ได้ตรวจ** (เช่น หน้าตาบนมือถือจริง)
