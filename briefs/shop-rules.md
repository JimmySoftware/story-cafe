# กฎของร้าน Story Cafe (เจ้าของร้านเขียนไว้)
> ข้อมูลสมมติเพื่อการเรียน · กฎพวกนี้ AI เดาเองไม่ได้ ต้องบอก

1. ราคาจริงอยู่ที่ `data/menu.csv` ที่เดียว ห้ามพิมพ์ราคาซ้ำในโค้ดหรือหน้าเว็บที่คำนวณเงิน
2. ยังไม่คิด VAT ห้ามเพิ่มบรรทัดหรือการคำนวณภาษีเอง (เจ้าของร้านจะถามนักบัญชีก่อน)
3. ข้อความที่เจ้าของร้านเห็นเป็นภาษาไทย ไม่มี stack trace: error ให้บอกว่าผิดที่ไหน แล้วหยุด
4. อ่าน brief ใน `briefs/` ก่อนสร้างหรือแก้ฟีเจอร์ เพราะ brief มีกฎที่เดาจากโค้ดไม่ได้
5. ห้ามอ่านหรือพิมพ์ไฟล์ `.env` และ `.env.local` (ไฟล์ความลับ) ถ้าต้องใช้ค่า ให้ใช้ผ่านตัวแปรสภาพแวดล้อม · `.env.example` อ่านและแก้ได้ เพราะมีแต่ชื่อตัวแปร ไม่มีความลับ
6. รัน `npm test` ก่อนบอกว่าเสร็จ ถ้าไม่ผ่านให้บอกตรง ๆ พร้อมผลที่ได้
7. commit โดยระบุชื่อไฟล์ทีละไฟล์ ข้อความ commit เป็นภาษาไทย ห้าม push เอง
8. ตอบและสรุปงานเป็นภาษาไทยเสมอ ศัพท์เทคนิคเป็นภาษาอังกฤษได้
