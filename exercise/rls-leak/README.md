# สาขาโจทย์: โน้ตลูกค้าของพนักงาน (ยังไม่ merge)
> ข้อมูลสมมติเพื่อการเรียน · ไฟล์ในโฟลเดอร์นี้ **ยังไม่ถูก apply** กับฐานข้อมูล (ไม่ได้อยู่ใน `supabase/migrations/`)

freelancer ส่งงานมาให้ร้านดู: ตาราง `staff_notes` ไว้ให้พนักงานจดว่าลูกค้าคนไหนแพ้อะไร ชอบอะไร (เช่น "แพ้ถั่ว", "ชอบลาเต้ร้อนหวานน้อย")
- ไฟล์ที่เปลี่ยน: `20261026100000_staff_notes.sql` (migration ใหม่ ไฟล์เดียว)
- คำอธิบายจาก freelancer: "ทำ RLS แล้ว ทดสอบแล้ว พนักงานเขียนและอ่านได้ ✅"
- ข้อมูลในตารางนี้ **เป็นข้อมูลส่วนบุคคล** (เบอร์โทร + ข้อมูลสุขภาพของลูกค้า) ห้ามหลุดถึงลูกค้าคนอื่นหรือคนที่ยังไม่ล็อกอิน
- พนักงาน = ผู้ใช้ Supabase Auth ที่มี `app_metadata.role = 'staff'` (ตั้งได้เฉพาะฝั่งเซิร์ฟเวอร์)
