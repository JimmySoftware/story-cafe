# Loyalty Card (บัตรสะสมแต้ม) — โดย freelancer

ระบบแต้มสะสมของ Story Cafe พร้อมใช้งาน ✅ ผ่านการทดสอบแล้ว

## ฟีเจอร์
- ซื้อทุก 25 บาท ได้ 1 แต้ม **ปัดเศษลงเสมอ** (ลูกค้าไม่เสียเปรียบ ร้านไม่เสียเปรียบ)
- **วันเสาร์ แต้มคูณ 2** คิดตามวันที่ตามเวลาไทย (Asia/Bangkok) ไม่มีปัญหาเขตเวลา
- ใช้แต้มแลกส่วนลดได้ 1 แต้ม = 1 บาท **แต้มไม่มีทางติดลบ** เพราะตรวจยอดคงเหลือก่อนหักทุกครั้ง
- **ใช้ได้เฉพาะแต้มของตัวเอง** ระบบดูจาก session ของคนที่ล็อกอินเท่านั้น

## โครงไฟล์
- `store.ts` ที่เก็บ · `points.ts` ได้แต้ม · `redeem.ts` ใช้แต้ม · `promo.ts` โปรวันเสาร์ · `index.ts` ทางเข้า
