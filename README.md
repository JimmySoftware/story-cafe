# Story Cafe — ชุดเริ่มต้นของคอร์ส Claude Code (ฉบับคาเฟ่)

Story Cafe เป็นร้านสมมติ ใช้เรียนทีละ "สูตร" (บทละหนึ่งสูตร): คัดลอก prompt ในสูตรไปวางใน Claude Code แล้วจะได้ผลที่เห็นได้ภายใน 3 นาที
ปลายทางของคอร์สคือโปรแกรมร้านที่ใช้ได้จริงของร้านเดียว (ข้อมูลร้านอยู่ใน `shop.txt` และตารางตั้งค่า ไม่ฝังในโค้ด)

## ในโฟลเดอร์นี้
| ไฟล์ | คืออะไร |
|---|---|
| `menu.txt` | เมนูของร้าน (ข้อความดิบที่เจ้าของร้านพิมพ์ไว้) |
| `shop.txt` | ข้อมูลร้าน (ชื่อ เวลาเปิด ช่องทางติดต่อ ของที่ขาย) |
| `briefs/` | brief หนึ่งหน้าของงานแต่ละบท (เขียนเป้าหมายและกฎของร้าน ก่อนสั่ง Claude) |
| `tools/check/` | ตัวตรวจประจำบท: `npm run check -- <เลขบท>` บอกผลเป็นภาษาไทยว่าผ่านอะไร ตกอะไร |
| `fonts/` | ฟอนต์ไทยแบบไม่มีหัว (Kanit, Sarabun) ใบอนุญาต OFL |

## สูตรทำงานอย่างไร
1. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `claude`
2. คัดลอก prompt ข้อ 1 ของสูตรไปวาง กด Enter เอง
3. รอผล แล้วรัน `npm run check -- <เลขบท>`
4. ข้อ 2 ของสูตรคือ "ลองพัง" ใช้เมื่อข้อ 1 ผ่านแล้ว

ข้อมูลในคอร์สนี้เป็นข้อมูลสมมติทั้งหมด · คอร์สนี้ไม่ใช่ผลิตภัณฑ์ทางการของ Anthropic
