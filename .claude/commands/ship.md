ทำตามลำดับนี้ **ทุกครั้ง ไม่ข้ามขั้น** ตอบและรายงานเป็นภาษาไทย

## 1. สำรวจ
- รัน `git status` และ `git diff --stat` แล้วบอกว่าแตะไฟล์อะไรบ้าง
- ถ้ามีไฟล์ที่ไม่เกี่ยวกับงาน (เช่น `.env`, ไฟล์ชั่วคราว) ให้หยุดและถามเจ้าของร้านก่อน ห้ามอ่านหรือพิมพ์เนื้อไฟล์ `.env`

## 2. แผน
- บอกสั้น ๆ ว่าจะตรวจอะไรและจะ commit ไฟล์ไหนบ้าง

## 3. ลงมือ
- ถ้ามีข้อที่ตกในขั้นถัดไป (ขั้น 4) ให้แก้เฉพาะสิ่งที่ตก ไม่ทำเกินงาน

## 4. พิสูจน์
รันให้ครบและรายงานผลจริงของแต่ละข้อ:
1. `npm test`
2. `npm run test:db`
3. `cd web && npm run build`
4. `node tools/rls-probe.mjs` (ตรวจว่าลูกค้าคนหนึ่งเห็นข้อมูลของอีกคนไม่ได้)

ถ้าข้อไหนรันไม่ได้ ให้บอกว่า "ไม่ได้ตรวจ" พร้อมเหตุผล ห้ามบอกว่าผ่าน

ถ้ามีข้อตกที่แก้เองไม่ได้ในขอบเขตงาน ให้**หยุดที่ขั้นนี้และรายงาน ไม่ commit**

## 5. commit
- ข้อความ commit เป็นภาษาไทย
- ระบุชื่อไฟล์ทีละไฟล์ (`git add <ไฟล์>`) ห้าม `git add -A` และ `git add .`
- ห้าม push (ตามกฎร้าน)

จบด้วยรายงานสรุปครบ 5 ขั้น และบอกสิ่งที่ยังตรวจไม่ได้ (เช่น หน้าตาจริงบนจอ)
